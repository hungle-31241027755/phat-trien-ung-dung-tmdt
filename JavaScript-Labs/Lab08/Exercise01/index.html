Để kiểm tra đúng Exercise 8.1, hãy mở phần cài đặt trang của trình duyệt, tắt JavaScript, tải lại trang rồi bật lại. Nội dung <noscript> chỉ xuất hiện khi JavaScript bị tắt thật.
